# 豆像素 · 照片转手作图纸

原生微信小程序，将照片转换为拼豆、十字绣或像素画图纸，支持预设图纸库、图纸导出与材料清单。界面内名称为「图纸 PATTERN」。

[观看作品展示视频](docs/demo.mp4) · [素材说明](docs/ASSETS.md) · [MIT 许可证](LICENSE)

## 功能

- 从相册选择照片，在设备端完成像素采样与颜色量化。
- 调节 20–120 列网格、4–32 色调色板，支持抖动开关、比例分析和居中裁剪。
- 导出带网格、符号和颜色用量的图纸。
- 按拼豆、刺绣、像素画浏览预设图纸，支持分类和排序。
- 计算拼豆颗数、拼板数量和成品尺寸，估算十字绣用线及绣布尺寸。
- 本机保存收藏、点赞、评价和评论。

## 快速开始

1. 克隆或下载本仓库。
2. 在微信开发者工具中选择「导入项目」，目录选本仓库根目录。
3. 使用自己的小程序 AppID。仓库内的 `touristappid` 是占位配置；如工具支持，可先使用测试号体验。
4. 编译后，从「生成」页面选择照片，或进入「图纸库」浏览预设。
5. 真机预览、相册保存和正式发布需要在自己的微信开发环境中验证。

小程序使用原生 JavaScript / WXML / WXSS 与 Canvas 2D，无 npm 运行时依赖，无需部署后端。项目配置的基础库版本为 3.0.0，建议在开发者工具中使用兼容的稳定版本。

## 算法与数据边界

`utils/pattern.js` 使用降采样、对比度处理、中位切分、k-means 细化及可选抖动生成图纸，同样的输入与参数应得到一致结果。这里的「智能生成」指本地图像算法，运行时不调用在线大模型。

图纸调色板使用 RGB/HEX 和符号，不承诺与某品牌拼豆或绣线的商业色号一一对应；采购前请自行核对实物颜色。拼豆颗数按有效填充格统计，板数按布局计算；十字绣线量属于经验估算，应预留余量。

图纸库的初始点赞数、评分和种子评论为演示数据。用户新增互动只保存在当前设备，没有账号同步或在线社区服务。照片生成的图纸保存在当前会话中，收藏摘要不能替代导出的图纸文件。

## 目录

```text

pages/index/           照片导入与图纸生成
pages/gallery/         图纸库
pages/detail/          图纸详情、材料方案与互动
pages/mine/            本地收藏与评价
utils/                 图纸算法、材料计算、本地存储和排序
data/                 预设图形、配色和演示数据
tools/                算法测试与可选素材处理脚本
docs/demo.mp4         用户提供的作品展示视频
```

## 自检

安装 Node.js（CI 使用 Node.js 22），无需安装 npm 包：

```bash
node tools/selftest.js
node tools/materials-test.js
node tools/library-test.js
```

这些脚本覆盖图纸算法、材料计算和图纸库数据；不能替代微信开发者工具与真机的界面、权限和导出测试。

可选的 Python 素材处理脚本需要 `numpy`、`scipy` 和 `Pillow`。运行现有小程序不需要 Python，也不需要重新构建素材。临时素材与中间像素文件位于 `tools/work/`，不会提交；如需重建，应自行提供具有使用权限的输入素材。
